# SFX for Editor v2

Drop royalty-free MP3/WAV files here. The editor mixes them on the timeline when present.

| File name | Use |
|-----------|-----|
| `whoosh.mp3` | Cut transitions |
| `bass-hit.mp3` | Zoom punches |
| `impact.mp3` | Hook hit |
| `rise.mp3` | Pre-drop tension |
| `glitch.mp3` | Flash frames |
| `ding.mp3` | Proof / tx confirmed |
| `camera-click.mp3` | Screenshot moments |
| `cash-register.mp3` | Ironic win/loss |
| `sub-bass.mp3` | Cinematic open |
| `keyboard.mp3` | Typing beats |

Editor v2 still renders finished MP4 without these — video + captions + cuts work; SFX layer is optional.
