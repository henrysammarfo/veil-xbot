# Kling / HeyGen / Hyperframes — reference only on free tier

**Free exports have watermarks. Do not post on X.**

Bot **does not** auto-use these for final renders. Instead:

| Provider | Bot behavior |
|----------|----------------|
| Kling | Skipped for export — use `npm run clips` → Pexels/Pixabay |
| HeyGen | Skipped — use screen recording + your face optional |
| Hyperframes | Skipped — use ffmpeg zoom + Pexels motion clips |
| Suno | **OK** — audio only, no watermark |
| Pexels/Pixabay | **Default b-roll** — bot finds URLs via TinyFish |

Removing watermarks from paid tools without license = don't. Use free stock instead.
